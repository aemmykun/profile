# profile

Neo glass card profile prototype built with vanilla HTML/CSS/JS.

## Preview

เปิดด้วย browser ใดก็ได้:

```bash
# linux
xdg-open index.html
# macOS
open index.html
```

สแต็กการ์ดตรงกลางสามารถแตะ/คลิกเพื่อให้การ์ดลอยขึ้นและแสดงรายละเอียดของแต่ละหัวข้อ (About, Experience, Projects, Contact) พร้อม motion tilt เบา ๆ ตามตำแหน่งเมาส์เหมือนตัวอย่างในรูปอ้างอิง.
